# دَرب — مشروع أندرويد

هذا مشروع Android Studio لتغليف موقع دَرب الإصدار الثامن داخل تطبيق WebView، مع تضمين HTML/CSS/JavaScript والصور محلياً.

## الحصول على APK
1. افتح المجلد في Android Studio (JDK 17 مع Android SDK 35 واتصال بالإنترنت لجلب Gradle والمكتبات).
2. اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
3. الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

أو ارفع هذا المشروع إلى مستودع GitHub، ثم من تبويب Actions شغّل **Build Darb APK** ونزّل مرفق **Darb-debug-APK** بعد نجاح المهمة.

## ملاحظات
- هذا تطبيق تجريبي؛ لا يتصل بسائقين أو نظام دفع أو قاعدة بيانات إنتاجية.
- محتويات الموقع الأساسية تعمل من ملفات التطبيق. قد يحتاج خط Cairo من Google Fonts إلى الإنترنت، ويمكن أن يستخدم النظام خطاً بديلاً دون اتصال.
- روابط خرائط Google الخارجية تُفتح في تطبيق خارجي عند وجوده.
- APK التجريبي الموقّع بمفتاح debug صالح للتجربة وليس للنشر على Google Play؛ النشر يتطلب توقيع release خاصاً.
- لم يُبنَ APK داخل هذه البيئة بسبب غياب Android SDK وGradle والوصول إلى خوادم التنزيل.

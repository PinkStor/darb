# دَرب - مشروع أندرويد جاهز للبناء

ارفع **محتويات هذا المجلد** إلى جذر المستودع `PinkStor/darb` بحيث يكون `app/build.gradle` في مكانه الصحيح، وليس `darb-android/app/build.gradle`.

ملف إعدادات البناء: `.github/workflows/build-apk.yml`. يشتغل مع الدفع إلى `main` أو التشغيل اليدوي من Actions.

بعد نجاح البناء: Actions → آخر تشغيل → Artifacts → Darb-Android-APK → `app-debug.apk`.

هذا إصدار تجريبي دون حجز أو دفع حقيقي.
